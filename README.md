# The Daily Plate

**A modern food and recipe blog featuring delicious meals, simple cooking instructions, and a warm, welcoming design.**

## About the Project

The Daily Plate is a responsive food blog created to help visitors discover recipes for breakfast, lunch, dinner, and dessert. It combines an attractive homepage with searchable recipe cards and individual recipe articles.

## Features

- **Responsive design:** Adapts to desktop, tablet, and mobile screens.
- **Recipe cards:** Displays recipe images, titles, categories, dates, descriptions, authors, and reading times.
- **Search:** Find recipes by title, description, or category.
- **Category filters:** Browse all recipes or filter by breakfast, lunch, dinner, and desserts.
- **Full recipe articles:** View ingredients and step-by-step cooking instructions.
- **Accessible interactions:** Includes descriptive image text, keyboard focus styling, and announcements for search results.

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Keniaumwali/the-daily-plate.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser, or use the VS Code Live Server extension.
